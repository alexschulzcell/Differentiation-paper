# 09_figures — Panel data, figures and the graphical abstract

Reshapes the stored analysis outputs into one CSV per panel (English throughout via `_display.py`), then draws the main and supplementary figures and the graphical abstract. Recomputes no statistic.

## Scripts

- `10_panel_data_main.py` — _repo-runnable_
- `11_panel_data_supplement.py` — _repo-runnable_
- `12_panel_data_second_cohort.py` — _repo-runnable_
- `20_figures_main.R` — _repo-runnable_
- `21_figures_supplement.R` — _repo-runnable_
- `30_graphical_abstract.py` — _repo-runnable_
- `_display.py` — _repo-runnable_
- `_glossary.py` — _repo-runnable_

_“repo-runnable” = reproduces from files in this repository alone. “needs raw data” = archival; requires the ~98 GB public raw data under `data_raw/` (see `00_setup.md`)._
