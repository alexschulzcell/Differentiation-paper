# 04_programme_decomposition — The three-way decomposition over all 18 data sets

Under a rule fixed in advance, each data set is split into: undifferentiated state left / lineage reached / matrix programme running. No data set leaves the undifferentiated state without the programme running.

## Scripts

- `10_decomposition_18_datasets.py` — _repo-runnable_

_“repo-runnable” = reproduces from files in this repository alone. “needs raw data” = archival; requires the ~98 GB public raw data under `data_raw/` (see `00_setup.md`)._
