# 07_in_vivo_growth_plate — Anchoring the programme in real skeletal development

Does the programme, defined in vitro, track maturation in vivo? The human fetal limb atlas (to the prehypertrophic zone) and the postnatal growth plate (a documented negative control: not calibratable, because hypertrophic cells switch the matrix programme off).
