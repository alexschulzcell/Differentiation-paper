# 10_manuscript_checks — Self-tests and submission packaging

`10_check_numbers.py` compares every load-bearing number in the manuscript against its panel file; `11`/`12` check the reference apparatus and the language rules; `20`/`21` build the Key Resources Table and the submission package.

## Scripts

- `10_check_numbers.py` — _repo-runnable_
- `11_check_references.py` — _repo-runnable_
- `12_check_language.py` — _repo-runnable_
- `20_key_resources_table.py` — _repo-runnable_
- `21_build_submission.py` — _repo-runnable_

_“repo-runnable” = reproduces from files in this repository alone. “needs raw data” = archival; requires the ~98 GB public raw data under `data_raw/` (see `00_setup.md`)._
